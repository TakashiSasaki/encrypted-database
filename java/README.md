# Java J1 Scaffold

* Java J1 scaffold exists as a minimal build harness and read-only metadata boundary.
* Java J1 scaffold is not a production storage library.
* Java J1 scaffold does not read or write Storage Format V1 databases.
* Java J1 scaffold does not perform encryption/decryption.
* Java J1 scaffold does not implement Argon2id, AES-GCM, SQLite, or generic JCS.
* Java J1 scaffold contains strict boundary validators for UUID, content-type, and metadata.
* Java is not baseline-public.
* Java is excluded from Python/Node.js first public release.
* Java publication is out-of-scope.
* Java Maven Central/GitHub Packages publication is out-of-scope.
* Java future work must prove read-only compatibility before write support.
